# 📓 Creating and Sharing a Jupyter Notebook

This repository demonstrates how to create a Jupyter Notebook, run basic code, and share it publicly using GitHub.

---

## 🚀 What’s Inside

- `DataScienceEcosystem.ipynb` — A sample Jupyter Notebook showing:
  - Markdown formatting (headings, lists, links)
  - Code cells (basic Python operations)

---

## 🧠 Skills Demonstrated

- Writing and structuring notebooks using Markdown
- Running Python code in Jupyter cells
- Saving and sharing a notebook publicly

---

## 🛠 Tools Used

- Jupyter Notebook (via Skills Network Labs)
- GitHub for sharing and version control
- Markdown for formatting

---

## 🔗 How to View

Click on the `.ipynb` file above to view it directly in GitHub.  
Or use [nbviewer](https://nbviewer.org) for a clean, rendered version by pasting this notebook’s GitHub link.
